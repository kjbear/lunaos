🔧 Technical Details

How It Works:

  1. User submits question on /tasks/executive/board
  2. Redirects immediately to /tasks/executive/board/{sessionId}
  3. Livewire component polls every 2 seconds: wire:poll.2s="refreshResponses"
  4. Queue worker processes debate asynchronously (5-minute timeout)
  5. Executives respond via Ollama Cloud GLM-5 API
  6. Responses saved to board_responses table incrementally
  7. Markdown rendered via marked.js on frontend
  8. CEO synthesizes final decision after all rounds complete

API Endpoints Added:

  • GET /api/board/sessions/{sessionId}/status – Poll session status
  • GET /api/board/sessions/{sessionId}/responses – Get all responses with metadata
  • POST /api/board/sessions/{sessionId}/start – Trigger background processing
