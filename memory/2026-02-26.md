## Design Patterns Established

**Consistent Elements Across All Views:**
1. **Header Cards** - Gradient glassmorphism with stats
   - `bg-gradient-to-br from-indigo-950/80 via-purple-950/80 to-slate-900/80`
   - Backdrop blur + border-white/10
   - Stats on right, icon + title on left

2. **Section Cards** - Unified card style
   - `bg-slate-900/60 backdrop-blur-sm rounded-2xl border border-white/10`
   - Hover states: `hover:border-purple-500/30 hover:shadow-lg`

3. **Color Coding** - Consistent throughout
   - Purple/Cyan/Pink gradients (primary branding)
   - Emerald (create/success actions)
   - Red (delete/deadlines/errors)
   - Blue (update actions)
   - Amber (warnings/medium impact)

4. **Interactive Elements** - Standardized
   - Search inputs with icon positioning
   - Filter buttons with active states
   - Click-to-expand pattern for details
   - Timeline dot indicators
