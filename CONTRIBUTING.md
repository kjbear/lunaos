# Contributing to LunaOS

Thank you for your interest in contributing to LunaOS! We welcome contributions from the community.

## How to Contribute

- **Fork and Branch**: Fork the repository and create a descriptive branch name for your changes (e.g., `feature/add-new-component` or `fix/resolve-auth-issue`).

- **Follow Coding Standards**: Adhere to Laravel 12 best practices, use strict types, include comprehensive docblocks, and ensure your code is testable.

- **Write Tests**: All new features and bug fixes must include corresponding tests. Run the existing test suite before submitting to ensure no regressions.

- **Submit a Pull Request**: Create a pull request with a clear description of your changes, reference any related issues, and be responsive to code review feedback.

## Questions?

If you have questions about contributing, please open an issue with the "question" label.

Thank you for helping make LunaOS better!
