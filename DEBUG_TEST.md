### ❌ CRITICAL: Toast Dispatch Method Incorrect

**Location:** `app/Livewire/Board/ExecutiveBoard.php::conveneBoard()`

**Current Code:**
```php
$this->dispatch('toast-warning', message: 'Please enter a question for the board.');
```

**Problem:**
The toast container listens to `@toast-warning.window` events (window-level events), but the component is dispatching to `$self` by default. 

**Fix:**
Change the dispatch calls to broadcast to window:
```php

// OR (Livewire v3 syntax):
$this->dispatch('toast-warning', message: '...'); // already broadcasts to window by default in v3
```
